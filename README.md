USAGE

git clone the repo

Use GNU stow
```sh
yay stow

```
An example usage:

```sh
stow dwm_srcs

```
Build the source files using make with root privileges.

```sh

sudo make clean install

```

Stow zsh and source to add path variables and other configurations

```sh
stow zsh
source .zshrc

```

Make them executable

```sh

chmod +x ~/.config/.local/scripts/*

```
